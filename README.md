# PRIMEVPN v100.0.0

Multi-tenant commercial VPN control plane for WireGuard, AmneziaWG and OpenVPN.

Railway hosts Web/API/Worker/Scheduler only. VPS nodes host VPN data plane, firewall/NAT, protocol daemons and Node Agent. VPN traffic never traverses Railway.

Implemented domains: tenant-scoped data model, RBAC roles/permissions, Argon2id authentication, JWT sessions, idempotent node provisioning task creation, protocol-specific inbound models, client lifecycle, session/traffic/quota models, audit model, restricted Node Agent, Alembic migrations, Docker and RTL administration UI.

API: /api/v1 with OpenAPI generated by FastAPI.

Security: tenant predicates are enforced in resource queries; out-of-scope IDs return 404; secrets are environment-only; Node Agent exposes allowlisted operations only.

Version: 100.0.0
